#MyMapleUnion

메이플스토리 캐릭터 42개의 정보(캐릭터명, 전직, 레벨)를 입력하고 저장·조회할 수 있는 Java Swing 데스크톱 프로그랩입니다.

## 핵심 특징 : DB 설치 없이 바로 실행
- **별도의 DB 서버 설치나 설정이 필요없습니다.**
- 프로그램을 처음 실행하면 로컬 DB 파일(mymapleunion.db)이 자동으로 생성되고, 입력한 데이터가 이 파일에 저장됩니다.
- 프로그램을 종료했다가 다시 실행해도 mymapleunion.db 파일만 있다면 이전에 입력한 데이터를 그대로 불러옵니다.
- 다른 컴퓨터로 옮길 때도 이 DB 파일만 함께 복사하면 데이터가 이어집니다.

## 주요 기능
- 캐릭터 정보(캐릭터명 / 전직 / 레벨) 입력 및 저장
- 캐릭터는 최대 42개까지만 등록 가능(유니온 점수 합산 기준)
- 레벨 높은 순 정렬 및 레벨 총합 표시
- 더블클릭으로 정보 수정

## 기술 스택
언어 : Java
UI : Swing
DB : SQLite(JDBC)
